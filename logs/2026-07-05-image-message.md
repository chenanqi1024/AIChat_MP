# 本次改动日志

## 新增文件
- `logs/2026-07-05-image-message.md`：记录本次图片消息功能实现。

## 修改文件
- `pages/chat/chat.js`：新增图片选择、格式与大小校验、Base64 Data URL 转换、预览、移除和随消息发送逻辑。
- `pages/chat/chat.wxml`：新增图片入口、待发送图片预览、消息气泡图片展示和图片预览事件。
- `pages/chat/chat.wxss`：新增图片按钮、待发送图片面板和图片消息气泡样式。
- `services/chat.js`：发送聊天请求时按需组装 `message` 与 `image` 字段，支持纯图片消息。

## 完成功能
- 支持从相册或相机选择 1 张图片。
- 支持 JPEG、PNG、WebP 图片，限制最大 6MB。
- 支持将图片转换为后端要求的 Base64 Data URL。
- 支持图片单独发送，或图片加文字一起发送。
- 支持发送前预览和移除图片。
- 支持在本地消息气泡中展示刚发送的图片。

## 当前仍未完成的内容
- 后端不会持久化图片，历史记录中纯图片消息仍会显示为 `[图片]`。
- 未实现多图发送。
- 未做真机图片选择和发送验证。

## 运行说明或注意事项
- 图片消息会调用 `/chat`，因此仍需要登录态和 ChatService 合法域名配置。
- 如果图片发送失败，优先检查图片大小、格式和微信小程序 request 合法域名设置。
